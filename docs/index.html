crm.sdk

A typed CRM library for AI agents. Contacts, deals, and pipeline in Postgres schema crm — call createCrm(), not a filesystem mount.

$ npm install crm.sdk

Built for how agents actually work

📦

Typed createCrm client

createCrm({ connectionString }) returns crm.contact, crm.deal, crm.search, crm.report. Strongly typed arguments in, records or thrown errors out. No MCP, no REST shim.

🤖

Agent skill

Copy skills/SKILL.md into .cursor/skills/crm-sdk/ (or claude skills add from GitHub). The skill is the method contract. Installing it does not replace npm install crm.sdk.

🔬

Deep normalization

E.164 phone normalization, website normalization, social handle extraction from URLs, entity merge with reference relinking, and fuzzy duplicate detection. What a spreadsheet can never provide.

🔎

Lookup by ref

Show and edit by id, email, phone (any common format), LinkedIn/X handle, or website. IDs are prefixed ct_ / co_ / dl_ / ac_.

🐘

Postgres schema crm

Four tables plus search_index in schema crm. JSON arrays are jsonb. You pass a connection string. No SQLite file, no FUSE mount.

📊

Pipeline reports

Built-in reports: pipeline summary, stage conversion, deal velocity, weighted forecast, stale contacts, won/lost. Callable as crm.report.*.

Quick start

Install the package, pass a Postgres URL, start managing contacts and deals.

Manage contacts

// Phone → E.164, LinkedIn URL → handle, company auto-linked
const crm = await createCrm({
  connectionString: process.env.DATABASE_URL,
})

const id = await crm.contact.add({
  name: "Jane Doe",
  email: ["jane@acme.com"],
  phone: ["+1-212-555-1234"],
  linkedin: "linkedin.com/in/janedoe",
  company: ["Acme"],
})

await crm.contact.show("jane@acme.com")
await crm.contact.show("(212) 555-1234")  // same contact

Track deals

await crm.deal.add({
  title: "Acme Enterprise",
  value: 50000,
  contact: ["jane@acme.com"],
  stage: "qualified",
})

await crm.deal.move(id, { stage: "negotiation" })
await crm.pipeline()
await crm.report.conversion()

Search, reports, import

await crm.tag(janeId, ["enterprise"])
await crm.find("fintech CTO")
await crm.report.stale({ days: 30 })
await crm.import.contacts(csvString)

Agent skill + SDK

Give the agent the method contract, then call typed methods. No MCP, no mount, no ls ~/crm. 

# Cursor — project skill
$ mkdir -p .cursor/skills/crm-sdk
$ cp node_modules/crm.sdk/skills/SKILL.md \
    .cursor/skills/crm-sdk/SKILL.md

# From this repo
$ cp skills/SKILL.md .cursor/skills/crm-sdk/SKILL.md

# Personal (all projects)
$ cp skills/SKILL.md ~/.cursor/skills/crm-sdk/SKILL.md

# Claude Code
$ claude skills add \
    https://github.com/bunkernine/crm.sdk/tree/main/skills
// The skill tells the agent to import the package
import { createCrm } from "crm.sdk"

const crm = await createCrm({
  connectionString: process.env.DATABASE_URL,
  phone: { default_country: "US" },
})

await crm.contact.list()
await crm.report.stale({ days: 14 })
await crm.find("fintech CTO")
await crm.close()
